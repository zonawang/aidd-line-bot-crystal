## Visual Reference & Fidelity

[手機示意](mockup-mobile.svg)與[桌面示意](mockup-desktop.svg)標示實際驗證寬度、排版、文案、素材位置及操作順序。SVG 為靜態設計，按鈕不送出請求，水晶／角色區塊是素材位置示意；不是已完成 Bot 或測試證據。實作沿用既有圖片，沒有新增品牌插畫或設計系統。

文字替代：單頁先顯示產品、模式及 A／B 身分，接著對話、已選生日與生命靈數、三張卡、三追問和日期／生命靈數捷徑，再呈現訊息／圖片輸入、雙選單及教學說明。375 寬度三卡直向，1280 寬度三卡並排、說明在右側。

## Layout & Responsive Rules

| 項目 | 375 CSS px 手機 | 1280 CSS px 桌面 |
|---|---|---|
| 頁面 | 16 px 兩側留白，內寬 343；自然垂直捲動，無整頁水平捲動 | 置中最大 1120；主欄 776、間距 24、教學欄 320 |
| 標題／模式 | 產品名、教學模式、目前身分清楚；選擇器可換行 | 標題與模式同列，選擇器保留可見 |
| 卡片 | 三卡各自整行，名稱／簡介／圖／選卡動作完整 | 三等寬欄，16 px 間距；每卡約 248 寬 |
| 追問／捷徑 | 各按鈕依長度換行、完整問題文字，不截成不可辨識省略 | 同樣可換行；三追問與額外捷徑分成兩個具名區域 |
| 輸入／選單 | 原生控制，按鈕至少 44 px 目標；選單圖片之外有文字動作 | 同樣原生控制；畫面加教學側欄，不增加後台 |
| 教學說明 | 操作區之後，可用原生 details 收合 | 側欄顯示簡短步驟，可收合次要說明 |

小於 1024 單欄；1024 起兩欄。只有 375／1280 為本次操作驗證基準，不新增廣泛瀏覽器／裝置矩陣。長文字折行，圖片最大寬度 100%，表單控制可縮到容器；沒有固定頁高或只能滑動的卡片入口。

## Screen-State Specification

| 狀態 | 具體內容／下一步 | 故事／驗收 |
|---|---|---|
| S1 初始／空 | 歡迎「選生日看看水晶建議，也可以直接詢問或傳圖片」；目前 A 或 B、諮詢／Echo 模式；日期、文字、圖片、指南均可進入。空歷史說明未有先前內容。 | US1.1、US3.2、US10.1；AC1.1.1、AC3.2.1 |
| S2 生日 | 標籤「生日」、原生日期與文字替代、例 2000-01-01、明確提交。錯誤「這個日期不存在，請重新選擇或輸入」，原輸入保留、可修正；不加年齡條件。 | US8.1、US4.2；AC8.1.1–AC8.1.3 |
| S3 成功／三卡 | 已選日期、生命靈數 4 的示例、教學用途說明；恰三個不同水晶。沿用七款卡池，示意可用紫水晶／粉晶／黃水晶，不表示固定推薦。每卡名稱、簡介、圖片與「選擇〈水晶名〉」。 | US8.2、US9.1；AC8.2.1–AC8.2.3、AC9.1.1 |
| S4 選卡／追問 | 被選水晶對應介紹、角色名／頭像，三個完整可點追問；另有選生日及有效生日後生命靈數捷徑，回三卡可用。不明卡 ID 提示重選，不回另一卡內容。 | US4.1、US4.2、US5.1、US9.1；AC9.1.2–AC9.1.3 |
| S5 等待／成功／錯誤 | 「正在整理回覆」文字；本機模擬 LINE 動作就近標示。完成回覆用繁體中文及角色名；錯誤說明重試或改用文字，等待清除。固定文字／圖片範例標示近結果，不把真實錯誤變成功範例。 | US2.1、US2.2、US7.1；AC2.1.1–AC2.2.3、AC7.1.1–AC7.1.3 |
| S6 記憶 | A／B 與目前身分可讀；歷史、空歷史、未能讀取／保存分開說明。切換時不帶另一身分的對話泡泡；重啟再選 A 的步驟放教學說明。 | US3.1、US3.2；AC3.1.1–AC3.2.3 |
| S7 選單／指南 | 主素材左右兩動作：切五宮格、開教學分享連結；五宮格保留閱讀指南／認識水晶／淨化方法／功效與佩戴／返回。使用指南別名沿用；文字動作另提供，不能依圖片 hotspot 才可操作。 | US6.1、US6.2；AC6.1.1–AC6.2.3 |
| S8 Echo | 常駐 Echo 模式、原樣文字回聲、「退出 Echo／回到諮詢」。圖片提示「Echo 模式只接受文字」，退出指令先處理，不作回聲。 | US1.2；AC1.2.1–AC1.2.3 |
| 全部的部分可用 | 圖／頭像／選單載入失敗保留名稱、介紹和動作；三卡視覺不可用時列三個文字選項。動態追問失敗仍提供三個相關教學替代問題且標示來源。 | AC5.1.3、AC6.1.3、AC9.1.3、AC4.1.3 |

## Legacy Parity & Content

原始 line-datetime-picker 的 sender 映射維持 ATHENA「智慧守護神 雅典娜」、VENUS「金星守護神 維納斯」、FORTUNE「命運之輪 莫伊萊」、COSMOS「星曜守護導師 艾蓮」。頭像分別沿用雅典娜.png、維納斯.png、莫伊來.png 及既有 COSMOS URL／環境覆寫；缺圖仍顯示名稱。

本階段補核對既有 line-flex-message/index.js 卡池：紫水晶、粉晶、黃水晶、綠幽靈、白水晶、黑曜石、鈦晶，名稱／簡介／圖片來源沿用。原「#水晶」與「今日水晶推薦」入口亦保留；日期後推薦仍是主展示旅程。介紹以教學情境呈現，不新增實證療效宣稱。

已核對 line-datetime-picker/setup-rich-menus.js 的各格動作；主選單第二格為 https://github.com/zonawang/zona-ai-learning-lab，保留教學分享連結；不執行其刪 alias 或設定預設選單的線上操作。設計沿用 alias／switch 語意，具體安全設定於後續整合處理。
