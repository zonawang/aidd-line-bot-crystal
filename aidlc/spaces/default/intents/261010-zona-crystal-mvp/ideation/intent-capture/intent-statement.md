# Zona Crystal — 一天教學 MVP 產品目標

## Problem Statement

將 Zona Crystal 整理成能展示、教學與分享的 LINE Bot，在一個工作天內交付可操作的核心旅程。時間優先於架構完整度與正式營運準備；流程與文件以足以實作及驗證為準。 [desc]

## Target Customer

本次面向 Bot 的展示者、教學者與學習者，讓他們能操作一條完整旅程，理解輸入、推薦與後續互動的關係。 [desc]

## Success Metrics

- 時限：需求、設計、實作、測試及最終驗證全部限制在一個工作天。 [desc]
- 示範：在本機或最簡單可用環境，完成「輸入生日 → 三張水晶推薦卡 → 選一張了解更多」的端到端流程。 [desc]
- 驗證：核心路徑測試通過；已知限制與延後項目有紀錄。正式營運準備不是完成條件。 [desc]
- 流程：完成全部適用的 AI-DLC 生命週期階段，以最小深度執行。 [desc]
- 停損：每項架構、環境、相依或設計問題最多調查十分鐘；超時採簡單替代方案、簡化需求或移出 MVP，不延長時程。 [desc]

## Initiative Trigger

使用者希望以 Zona Crystal 完成一次可展示、教學與分享的 MVP 開發，並保留完整生命週期及關鍵驗證。 [desc]

## Initial Scope Signal

Workflow-selected：`zona-crystal-one-day`。此名稱代表流程選擇，不另行增加產品功能。 [scope]

產品邊界：生日輸入、水晶三卡推薦、選卡介紹；優先確保這條旅程可以實際示範。圖片辨識、永久記憶、進階占星與正式營運準備，除非核心旅程必需，否則延後。 [desc]
