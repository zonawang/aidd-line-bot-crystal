## Constraint Register

| ID | 類別 | 限制 | 對交付的影響 |
|---|---|---|---|
| C1 | 時間 | 整個生命週期限一個工作天 | 文件精簡；先完成可操作旅程，再做非必要完善 |
| C2 | 停損 | 每項問題最多調查十分鐘 | 超時就替代、簡化或延後，留下紀錄 |
| C3 | 範圍 | 生日、三卡推薦、選卡介紹 | 照片辨識、永久記憶、進階占星延後 |
| C4 | 驗收 | 本機或最簡單可用環境須能端到端操作 | 文件與範例訊息本身不足以宣告完成 |
| C5 | 外部依賴 | LINE 憑證與公開連線未驗證 | 保留串接入口，以不需金鑰的本機展示繼續；實機另驗 |
| C6 | 資源 | 不新增核心展示不需要的雲端帳號或付費服務 | 採購、正式部署與營運準備延後 |
| C7 | 資料 | 展示端不永久保存生日或完整對話 | 示範使用虛構生日；不能作出 LINE 平台不處理資料的承諾 |
| C8 | 內容 | 推薦與生命靈數是教學情境 | 不宣稱醫療效果或經驗證的命運判斷 |
| C9 | 品質 | 關鍵路徑測試須通過，限制須記錄 | 簡化範圍時仍保留核心驗證；不承諾正式營運品質 |
