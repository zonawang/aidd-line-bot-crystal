## Main Journey — IB1

進入 S1 → 選日期或輸入生日 S2 → 有效日期 → 生命靈數與三張不同水晶卡 S3 → 點選任一卡 → 對應水晶介紹 S4 → 點選三個追問之一 → 諮詢 S5 → 取得角色化回覆與新的三個追問 → 下一回合延續記憶 S6。

錯誤分支：S2 無效日期 → 說明錯誤 → 重新選擇／輸入 S2。其他諮詢與指南入口仍可使用；錯誤生日不產生生命靈數或卡片結果。

部分可用分支：S3 圖片不可用 → 同名文字卡與動作；卡片呈現不可用 → 三個文字選項 → S4。選卡介紹始終對應被選水晶。

## Consultation & Memory — IB3–IB5

S1／S4／S7 → 文字或圖片輸入 S5 → 等待提示 → 主題對應角色回覆 → 三個後續問題 → 點選一題或繼續自由輸入 → 讀取同一使用者必要記憶 → 回覆並保存可供後續讀取的內容。

圖片分支保留圖片送入真實模型的路徑；本機固定辨識結果有明確範例標示。四個角色均依既有主題規則保留；等待提示在成功與失敗時都會結束。

失敗分支：諮詢不可用 → 重試或返回入口；圖片處理失敗 → 重傳或改用文字。記憶讀寫失敗 → 如實提示未讀取／未保存 → 可繼續諮詢，不把缺失的歷史或保存結果冒稱成功。

回憶驗證旅程：使用虛構展示使用者 A 聊天 → 詢問先前內容 S6 → 重新啟動 → 同一 A 再詢問 → 仍能讀回。另一展示使用者 B 不得讀到 A 的記憶；沒有歷史的 B 從新對話開始。這是後續驗證要求，尚不是實測結果。

## Menu & Guides — IB6

S1 主選單 → 切至五宮格 S7 → 返回主選單。兩種選單均沿用原有素材與既有觸發動作，不重新設計格子。

既有指南入口 → 使用指南／使用說明／閱讀指南、認識水晶、淨化方法或功效與佩戴 → 閱讀內容 → 返回選單或直接繼續文字／圖片諮詢。選單切換不可用時，以同名文字入口與返回動作完成導航；本機模擬與真實 LINE 切換驗證分開。

## Echo Teaching Journey — IB2

使用指南／本機展示入口 → S8 Echo 模式提示 → 輸入文字 → 原樣文字回覆 → 可重複示範 → 退出 Echo → 返回一般諮詢入口。非文字輸入得到模式提示，退出動作不被當作一般回聲文字。

## Teaching Demonstration — IB7

本機啟動 → 清楚看到教學模式 → 主旅程 → 指南與選單往返 → 文字／圖片範例 → 等待及四角色 → 三個追問 → 記憶回憶與重啟 → Echo 及退出 → 教學說明中的已測試、模擬與待驗證清單。

真實外部依賴可用時，另從 LINE 手機進入相同功能旅程；日期、Flex 卡片、Quick Reply、角色、雙選單及 Loading Animation 逐項操作確認。本機展示完成不能推論真實外部測試全部通過。

| CAP7 | S5；IB5 | 等待開始、成功／失敗後結束 |

| CAP9 | S3、S4；IB1 | 三張不同卡與三個選卡內容對應 |
