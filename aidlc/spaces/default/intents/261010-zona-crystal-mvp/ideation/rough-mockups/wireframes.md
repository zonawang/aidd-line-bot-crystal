## Presentation Rules

以下以結構描述代替高擬真圖片，沿用原有角色、水晶、選單與指南素材。S1–S8 是同一產品的互動狀態，不要求新增八個頁面。LINE 使用原生對話、卡片、日期與選單；本機教學頁提供可操作的對應呈現，不能當作 LINE 實機驗證。

本機頁首常駐「Zona Crystal｜本機教學模式」。模擬模型回覆註記「教學範例回覆」；模擬圖片結果註記「圖片辨識範例，非真實辨識」；模擬選單或載入提示註記「LINE 操作模擬」。真實模式不顯示虛假的模擬標示。驗證狀態放在教學說明區，日常對話不呈現金鑰或設定細節。

## Information Hierarchy

1. 目前對話與最新結果：角色、回答、生命靈數或選卡內容。
2. 立即可操作動作：輸入、選日期、圖片、選卡、三個追問。
3. 導覽：雙選單、指南、返回與 Echo 模式。
4. 本機教學說明：展示步驟、模擬標示、外部尚待驗證項目。

## Screen Sketches

### S1 — 初次進入／首頁（CAP1、CAP6、CAP8、CAP10）

- 頂部：Zona Crystal 名稱；本機另有教學模式標示。
- 對話：簡短歡迎與「選生日看看水晶建議，也可以直接詢問或傳圖片」。
- 動作：「選擇生日」、文字輸入、圖片入口；底部沿用主 Rich Menu。
- Echo 在使用指南與本機展示入口可找到；生日不是使用其他功能的先決條件。
- 空對話有上述提示；有歷史時呈現可讀回的對話並保留相同入口。
- 無障礙：本機 h1 產品名、h2 對話；header/main/nav/footer；鍵盤起點為有標籤的文字輸入，所有動作可 Tab 抵達。LINE 使用原生控制，能力待實機確認。

### S2 — 生日輸入與修正（CAP8）

- 對話：「請選擇或輸入生日，例如 2000-01-01」。
- 動作：LINE 原生日期選擇；本機日期輸入與文字替代；可返回主入口。
- 成功：顯示已選日期，接續生命靈數與三卡；亦保留「了解我的生命靈數」追問入口。
- 錯誤：例如 2000-02-30，顯示「這個日期不存在，請重新選擇或輸入」；不生成結果，其他功能仍可使用。
- 無障礙：本機 h2 生日、h3 輸入提示；main/nav；鍵盤起點為生日欄位，錯誤連結對應欄位並可重新輸入；LINE 提供文字替代。

### S3 — 生命靈數與三卡（CAP8、CAP9）

- 對話：已選生日、生命靈數及教學用途的簡短解讀。
- 下方：三張不同水晶卡；每卡包含既有圖片、水晶名稱、短介紹及「了解這顆水晶」動作。
- 行動：選任一卡進入 S4；可重新輸入生日或返回主入口。
- 部分可用：圖片無法載入仍顯示水晶名、文字內容與可操作按鈕；卡片呈現失敗提供三個文字選項。
- 無障礙：本機 h2 推薦水晶、h3 每卡名稱；main/nav；鍵盤起點為第一卡動作，名稱與動作有明確關聯，圖片有替代文字。LINE Flex 保留可讀文字與訊息替代說明。

### S4 — 選卡內容與追問（CAP3–CAP5、CAP9）

- 頂部／回覆：對應角色名稱及頭像；選中水晶名稱與介紹，不能把其他卡的內容混入。
- 下方：三個可點選後續問題，例如「如何淨化這顆水晶？」；依目前內容產生，不固定冒稱動態 AI。
- 行動：追問進入 S5；也可回到三卡或使用指南。
- 部分可用：動態追問失敗仍提供三個與目前內容相關的教學替代問題，適用時標示範例。
- 無障礙：本機 h2 水晶介紹、h3 後續問題；main/nav；鍵盤起點為第一追問，按鈕以完整問題作標籤；頭像旁有角色文字。

### S5 — 文字／圖片諮詢與等待（CAP2–CAP5、CAP7）

- 輸入：使用者文字或圖片；水晶與既有星座情境均可詢問。
- 等待：LINE Loading Animation；本機顯示「正在整理回覆」及 LINE 操作模擬標示，不用純顏色表示狀態。
- 成功：主題對應角色的名稱／頭像、回覆及三個後續問題；下一回合讀取該使用者必要記憶。
- 四角色沿用：智慧守護神 雅典娜、金星守護神 維納斯、命運之輪 莫伊萊、星曜導師 艾蓮。圖片不是獨立替代文字的唯一資訊。
- 錯誤：諮詢失敗可重試；圖片無法處理提示重傳或改用文字。等待結束後仍保留輸入，不出現假的成功回覆。
- 無障礙：本機 h2 諮詢、h3 回覆角色；main/nav；鍵盤起點為訊息輸入或有標籤的圖片選擇，等待與完成用可讀狀態提示，不搶走輸入焦點。

### S6 — 記憶與回憶（CAP3）

- 操作：在對話詢問「你還記得我剛才聊過什麼嗎？」；教學說明提示可重新啟動後再詢問。
- 有記憶：以必要內容延續，不呈現別人的對話；空記憶：「目前沒有先前對話，我們可以從這裡開始」。
- 讀寫失敗：提示「先前對話暫時無法讀取」或「這次內容未能保存」，可繼續一般諮詢；不宣稱已成功保存。
- 無障礙：本機 h2 記憶回覆；main/nav；鍵盤起點仍為對話輸入，記憶狀態有文字，不新增難以操作的記憶控制頁。LINE 以文字回覆。

### S7 — 雙選單與指南（CAP6）

- 主選單：沿用原有素材與指南入口；切換動作前往五宮格。
- 五宮格：沿用原有素材與動作；返回動作切回主選單。格子的既有文案與觸發行為在實作時逐一核對，草圖不重畫或新增格子。
- 指南：使用指南／使用說明／閱讀指南、認識水晶、淨化方法、功效與佩戴；文字與可用圖片隨對話顯示。
- 每份指南可返回選單或繼續諮詢。選單未顯示或切換失敗時提供同名文字入口與返回動作。
- 無障礙：本機 h2 選單／指南、h3 指南小節；main/nav；鍵盤起點為首個具名選單按鈕，圖片區域另有文字動作；LINE 文字指令作替代入口。

### S8 — Echo 教學模式（CAP1、CAP10）

- 從使用指南或本機展示入口進入；常駐「Echo 模式」提示。
- 使用者輸入文字後原樣回覆，讓教學者展示訊息接收與回覆。
- 明確「退出 Echo／回到諮詢」動作；退出後恢復 S1／S5。圖片等非文字輸入提示本模式接受文字，不冒稱 AI 辨識。
- 無障礙：本機 h2 Echo 模式；main/nav；鍵盤起點為文字輸入，模式變更及退出按鈕有可讀名稱；LINE 可用文字指令退出。

## Mobile & Desktop Adaptation

LINE 手機沿用原生對話與水平三卡。本機窄螢幕把對話、操作與可收合教學說明依序排放；三卡可水平查看或直向堆疊，但所有卡都能鍵盤操作。桌面以對話為主區、教學說明為旁區，避免新增管理後台。圖片輸入、日期與指南均提供文字說明，不依賴滑動手勢才能完成主旅程。

## MVP Boundary & Validation Handoff

S1–S8 覆蓋 CAP1–CAP10；[user-flow.md](user-flow.md) 描述跨狀態路徑。後續需逐項實作並驗證：生日錯誤復原、三卡不同與內容對應、追問、四角色、等待、圖片路徑、使用者隔離與重啟記憶、選單往返、各指南與 Echo 退出。

草圖不是功能完成證據，也不是 WCAG 認證。本機、真實模型／記憶服務及 LINE 手機證據分列；缺少外部依賴時如實標示待驗證。一日內不新增品牌裝飾或完整管理頁，不刪除既有功能。
