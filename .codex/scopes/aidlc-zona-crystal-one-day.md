# Zona Crystal 一日 MVP

Guard Policy 採 strict：不降低任何防線，核准後輸入改變即重新開啟相應核准。

以可展示、教學與分享為目的，一個工作日內完成所有適用階段，每階段只產出最小足夠成果，Test Strategy 為 Minimal，驗證核心旅程及必要錯誤路徑。

核心旅程：輸入生日、取得三張水晶推薦卡、選一張查看介紹；採固定水晶目錄、共用處理器與免 API key 的本機展示，保留可接 LINE webhook 的入口。

延期項目：圖片辨識、永久記憶、進階占星與正式環境整備。未經真實 LINE 整合測試，不宣稱線上驗證成功。

任何架構、基礎設施、相依套件、環境或設計問題調查最多十分鐘，到限立即採最簡可行替代方案或縮減需求，不延長一日上限。
