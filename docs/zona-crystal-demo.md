依 README 啟動，開 http://127.0.0.1:8080，選 A；目前模式应顯示「諮詢模式」。結果附近區分「教學範例回覆」「圖片辨識範例，非真實辨識」「教學替代問題」「LINE 操作模擬」。

1. 輸入 2000-01-01 → 生命靈數 4、三張不同卡。逐卡點選，介紹應符合名稱；每次的三個追問逐題點選會完整送出。生日表單也可輸入 2000/01/01、2000年1月1日、2000 01 01、20000101 或「我的生日是 2000-01-01」。
2. 用文字生日 2001-02-29 → 提示修正，輸入留存；改 2000-02-29 → 有效。2000-01-08、2000-09-29、1999-11-12 分別得到 2、4、6。可用獨立推薦不提供生日。
3. 點「了解我的生命靈數」另有三追問，送出原完整問題「老師，請幫我解析我的生命靈數是 4」，不重新抽卡。
4. 逐組點四角色輸入；名称／頭像如下。範例角色是固定主題規則，不能作為真模型品質證據。
5. 文字諮詢水晶、星座，检查三個可點追問。上傳 test/u1-zona-crystal-bot/fixtures/valid-image.png 或自己的 JPEG／PNG／WebP（最多 5 MiB），結果明示图片範例；無效檔重傳或改文字。
6. 進入回聲模式，送「你好水晶」应原樣回覆。圖片应提示只接受文字。按退出或送「退出 Echo」「離開 Echo」「結束 Echo」，返回諮詢；退出文字不回聲。
7. 逐一打開使用指南、使用說明、閱讀指南、認識水晶、淨化方法、功效與佩戴；內容沿用原文並加教學提醒。切到五宮格再回主選單，各格同名指南／返回控制与原分享链接仍可操作。圖片失敗時用文字按鈕。
8. A 送「我收藏紫水晶」並回憶；切 B，畫面清除 A 的回覆與表單、回憶不得出现 A；切回 A 回憶。Ctrl+C 停止、npm start 重啟，再明確選 A 點回憶，應延續 A。
9. 等待可读「正在整理回覆 · LINE 操作模擬」，成功／錯誤／逾時结束后可再操作；在途仍可切 A／B，晚到 A 不顯示在 B。不自动重送。
10. 以 Tab／Shift+Tab 到表單、卡、追問、選單与身分，檢查焦點與標籤；375／1280 CSS px 的人工驗證記錄见 evidence，未驗項不能當通過。
